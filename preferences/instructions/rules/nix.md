# Nix

- Don't edit `flake.lock`; it's generated by nix.
- Flakes only see git-tracked files: `git add` a new file before evaluating or
  building, or it fails with "path does not exist".
- Format with `nixfmt-tree` (`treefmt`); `statix check` and `deadnix --fail`
  must pass. They run as lefthook pre-commit hooks from the devShell.
- Keep evaluation pure: no `--impure`, no `builtins.getEnv`, no usernames or
  home paths in tracked files.
- Use `mkShellNoCC` for devShells unless a C toolchain is actually needed.
- Not test-driven. Verify by building, not activating
  (`nix build ... --no-link`). Never run `darwin-rebuild switch` or
  `home-manager switch` yourself; activation is mine to run.
