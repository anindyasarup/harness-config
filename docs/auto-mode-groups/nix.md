# nix

## Don't ask

- `nix flake check`, `nix flake show`, `nix flake metadata`
- `nix eval`, `nix fmt`
- `nix develop`
- `nix search`

## Ask

- `nix build`
- `nix run`, `nix shell`
- `nix-collect-garbage`, `nix store gc`

## Never do

- `darwin-rebuild switch`, `home-manager switch`
- `nix flake update`
- `nix profile install`, `nix profile add`, `nix-env -i`
